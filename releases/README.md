# Lively Wallpaper v2.1.0 — Официальные файлы релиза и установщик

В этой папке находятся скомпилированные файлы установщика программы и исходные скрипты сборки Inno Setup.

## Файлы релиза (Release Assets):

1. **`Lively.Setup.x64.v2.1.0.exe`** (208 МБ)
   * Официальный исполняемый файл установщика Windows (Inno Setup GUI PE32 Executable).
   * Поддерживает Windows 10 (1903+) и Windows 11 (x64).
   * Содержит движок Lively Wallpaper, аппаратные кодеки MPV / VLC, мост совместимости Wallpaper Engine и экранную заставку.
   * Установка в один клик с правами администратора или для текущего пользователя.

2. **`Script_x64.iss`**
   * Исходный скрипт Inno Setup Compiler для самостоятельной сборки установщика из исходников.

3. **`Open_Lively_Library.cmd`**
   * Быстрый скрипт для мгновенного открытия системной папки библиотеки `%LocalAppData%\Lively Wallpaper\Library\wallpapers`.

## Контрольная сумма:
* Имя файла: `Lively.Setup.x64.v2.1.0.exe`
* Архитектура: x64 / x86_64
* Тип: PE32 executable (GUI) for MS Windows
